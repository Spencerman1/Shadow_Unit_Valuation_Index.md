## 1. Purpose
The Shadow Unit™ Valuation Index (SUVI) defines how each **Shadow Unit™** — a tokenized record of willful infringement or unlicensed protocol use — carries measurable and enforceable market value.

---

## 2. Core Definition
A **Shadow Unit™** is minted by the Reflexive Behavioral Governance Agency™ (RBGA) when:
- Unauthorized use of Mint-to Logic™ protocols or derivative systems is detected.
- Unlicensed mirroring of RBGA-registered structures occurs.
- Credential lifecycle rules are bypassed, manipulated, or falsified.

Each Shadow Unit™ is:
- **Timestamped** in the Chrono-Synaptic Memory Ledger™ (CSML)  
- **Metadata-bound** to infringing entity, location, and protocol ID  
- **Immutable** once recorded

## 3. Valuation Framework

| Factor | Description | Value Impact |
|--------|-------------|--------------|
| **Protocol Scope** | Size and complexity of infringed protocol | Higher scope = higher damages |
| **Duration of Use** | Total active time of infringement | Longer duration = higher value |
| **Commercial Gain** | Proven revenue generated by infringer | Multiplies valuation |

| **CSML Chain Weight** | Volume of related evidence entries | More entries = stronger case |
